# Pakiety i limity linków – plan implementacji (etap 1)

> **Dla agentów wykonawczych:** WYMAGANY SUB-SKILL: użyj superpowers:subagent-driven-development (zalecane) albo superpowers:executing-plans, żeby wykonać plan zadanie po zadaniu. Kroki używają checkboxów (`- [ ]`).

**Cel:** Super administrator zarządza pakietami (nazwa, limit linków, ceny per okres) i przypisuje je użytkownikom; limit pakietu blokuje tworzenie nowych linków.

**Architektura:** Dwie nowe tabele (`packages`, `package_assignments`), logika pakietu efektywnego w `User`, egzekwowanie przez `LinkPolicy::create` i `UserPolicy::createLink`. Panel admina dostaje CRUD pakietów i kartę przypisania na stronie użytkownika. Rozwiązanie pod późniejszy Cashier: `package_assignments` jest źródłem prawdy.

**Tech Stack:** Laravel (PHP 8.5), Inertia v3 + Vue, Wayfinder, Pest, Pint.

**Spec:** `docs/superpowers/specs/2026-10-09-packages-design.md`

## Global Constraints

- Wszystkie nowe tabele z kluczami UUID (PK i FK): `HasUuids`, `foreignUuid`.
- Pakietami zarządza i przypisuje je wyłącznie super administrator; pozostałe role dostają 403.
- Ceny w groszach (`unsignedInteger`, nullable); pusta cena = okres niedostępny.
- Okresy (`BillingPeriod`): `one_time`, `monthly`, `quarterly`, `yearly`. Dla cyklicznych `expires_at` = `starts_at` + 1 / 3 / 12 miesięcy; dla `one_time` ręczna data.
- Jeden wiersz `package_assignments` na użytkownika (unikalny `user_id`); nowe przypisanie zastępuje stare.
- Pakiet efektywny: super admin → brak limitu (`null`); aktywne przypisanie (`expires_at` w przyszłości) → jego pakiet; inaczej pakiet `is_default`; brak domyślnego → limit 0. Wygaśnięcie liczone przy odczycie, bez crona.
- Limit liczy wszystkie linki użytkownika i blokuje tylko tworzenie nowych.
- Bez Cashiera i kolumn Stripe; nie zmieniać zależności.
- Konwencje projektu: Form Requests, `Gate::authorize`, `Inertia::flash('toast', …)`, nazwane trasy, Wayfinder, typy zwrotne, Pest. Kod i komunikaty UI po angielsku.
- Po zmianach PHP: `vendor/bin/pint --dirty --format agent`. Pełny zestaw testów uruchamia użytkownik (`php artisan test --compact`).

## Decyzje planu (poza specem – do potwierdzenia)

- Migracja danych wstawia domyślny pakiet „Free” (`link_limit` 10, brak cen, `is_default`), żeby istniejący użytkownicy i istniejące testy nie zostały zablokowane limitem 0. `RefreshDatabase` zachowuje ten wiersz między testami; testy „brak domyślnego” kasują go jawnie.
- Limit dotyczy właściciela linku: gdy admin dodaje link w imieniu klienta (`UserLinkController`), liczy się limit klienta.
- Przypisanie pakietu superadminowi jest odrzucane (403).
- Wyścig count-then-insert przy równoległych żądaniach jest akceptowany (znany pułap, bez blokad).

## Review Focus

- Użytkownik z `link_limit` 0 lub bez żadnego pakietu: „Nowy link” zablokowany, istniejące linki działają (Zadanie 3).
- Przypisanie wygasłe dokładnie teraz (`expires_at` = `now()`) traktowane jako nieaktywne (Zadanie 2).
- Admin tworzący link klientowi, który osiągnął limit, dostaje 403 (Zadanie 3).
- Przypisanie okresu bez ceny w pakiecie, oraz pakietu bez żadnej ceny (domyślny Free), jest odrzucone z błędem walidacji (Zadanie 5).
- Usunięcie pakietu domyślnego lub używanego jest zablokowane, a zmiana `is_default` zostawia dokładnie jeden domyślny (Zadanie 4).
