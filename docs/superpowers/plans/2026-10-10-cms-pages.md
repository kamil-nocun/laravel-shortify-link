# Podstrony CMS z wersjonowaniem — plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Panel admina do tworzenia i edycji podstron (WYSIWYG) z niezmienną historią wersji oraz publiczny widok `/content/{slug}`.

**Architecture:** `Page` wskazuje aktualną `PageVersion`; każdy zapis treści przechodzi przez jedną akcję `SavePageVersion`, która sanitizuje HTML i tworzy nową wersję. Panel jest zwykłym zasobem `admin/pages` chronionym `Permission::PagesManage` i `PagePolicy`, publiczny widok to osobny kontroler.

**Tech Stack:** Laravel, Inertia v3 + Vue 3, Pest, `symfony/html-sanitizer` (MIT), TipTap `@tiptap/vue-3` + `@tiptap/starter-kit` (MIT).

**Spec:** `docs/superpowers/specs/2026-10-10-cms-pages-design.md`

## Global Constraints

- Nowe tabele: klucze główne i obce UUID (`HasUuids`, `foreignUuid`).
- Zależności tylko na licencji MIT; zatwierdzone wyłącznie: `symfony/html-sanitizer`, `@tiptap/vue-3`, `@tiptap/starter-kit` (plus rozszerzenie linków, jeśli nie jest w starter-kit).
- Adres publiczny: `/content/{slug}`, nazwa trasy `content.show`; trasa musi być zarejestrowana przed `{code}`.
- Slug: unikalny, `[a-z0-9-]+`. Wersje są niezmienne (brak `updated_at`).
- Jeden język, bez usuwania stron, bez wielojęzyczności.
- Konwencje repo: tekst UI po angielsku w `__()`/Vue, kontrolery cienkie, logika w `app/Actions`, Form Requests w `app/Http/Requests/Admin`, testy Pest w `tests/Feature/Admin`, `vendor/bin/pint --dirty --format agent` po zmianach PHP.

## Review Focus

- Slug z wielką literą, spacją, `_` lub samymi myślnikami: walidacja odrzuca; `/content/Privacy` (wielka litera) daje 404.
- HTML z `<img onerror>`, `<a href="javascript:...">`, `<iframe>`, `<style>` i niedomkniętymi tagami: wynik nie zawiera aktywnej treści, strona się nie wysypuje.
- Pusta treść lub sam biały znak: odrzucona walidacją (`body` required).
- Przywracanie wersji innej strony (`/pages/A/versions/{wersjaB}/restore`): 404, nie przywraca.
- Strona `Published` z `current_version_id = null` oraz usunięty autor wersji (`created_by` null): publiczny widok i historia działają.
- Edycja bez zmiany tytułu i treści (np. tylko slug): nie tworzy zbędnej wersji.
